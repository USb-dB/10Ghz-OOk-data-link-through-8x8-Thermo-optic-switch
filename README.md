MATLAB simulation and analysis of a **10 GHz On-Off Keying (OOK) Intensity-Modulated Direct-Detection (IM-DD)** optical link through a programmable **8×8 thermo-optic Mach–Zehnder Interferometer (MZI) switch**. The workflow evaluates signal integrity across multiple routing states using eye-diagram characterization and Bit Error Rate (BER) analysis, demonstrating the transmission performance of reconfigurable silicon photonic switching networks for scalable Programmable Photonic Integrated Circuits (PICs).


## MATLAB Simulation Workflow

The repository focuses on the receiver-side MATLAB analysis of captured OOK waveforms. The processing pipeline performs waveform sampling, Automatic Gain Control (AGC), normalization, adaptive threshold detection, BER computation, and eye-diagram generation for multiple switch configurations. The provided scripts reproduce the performance comparison shown in the accompanying figure through a fully automated post-processing workflow.
